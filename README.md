# Draughts Corpus Engine

Исследовательская платформа для корпуса партий в русские шашки: импорт PDN,
просмотр партий, быстрый поиск по позиции, статистика продолжений и постепенно
подключаемые аналитические инструменты.

## Текущий этап — v0.2 corpus

Уже реализовано:

- TypeScript + React + Vite;
- одна кодовая база для Web и Android (Capacitor);
- четыре `uint32` bitboard и упаковка позиции в два `uint64` (`bigint`);
- сторона хода входит в канонический ключ позиции;
- русская буквенно-цифровая нотация (`c3-d4`, `d4:f6`);
- алгебраический FEN по умолчанию; numeric FEN читается только для совместимости;
- импорт основной линии PDN;
- проигрывание тихих ходов, взятий, дамок и превращения во время серии взятий;
- просмотр партии по позициям;
- in-memory словарь уникальных позиций;
- обратный индекс `позиция → партии`;
- статистика продолжений и результатов для выбранной позиции;
- тесты и GitHub Pages workflow.

PDN для русских шашек должен использовать `GameType "25,W,8,8,A0,0"`. Пользовательский
интерфейс проекта не использует цифровую нотацию полей; внутренний индекс 1..32 нужен
только для адресации битов.

## Запуск

Нужен Node.js 24 или новее.

```bash
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run build
```

## Android

```bash
npm install
npm run build
npm run android:add
npm run android:sync
npm run android:open
```

Debug APK также собирается через GitHub Actions.

## GitHub Pages

После push в `main` workflow собирает `dist/` и публикует приложение через GitHub Pages.

## Ограничения текущего импортера

`v0.2` — первый вертикальный срез корпуса, а не окончательный PDN 3.0 parser.
Сейчас импортируется основная линия. Комментарии и варианты удаляются при построении
индекса, а исходный текст партии сохраняется в памяти. Следующий parser должен строить
полный AST и сохранять комментарии, варианты, NAG и исходное представление без потерь.

Перед массовой загрузкой исторического корпуса будет добавлен полный генератор легальных
ходов русских шашек. Это позволит разрешать сокращённые записи взятий и проверять
обязательность взятия, а не только геометрию явно записанного хода.

## Следующие задачи

1. Полный генератор легальных ходов: обязательное взятие, выбор любой доступной серии,
   простая назад при взятии, летающая дамка, превращение внутри серии.
2. Tolerant PDN 3.0 parser + AST и lossless экспорт.
3. Постоянное хранилище: IndexedDB для локальной библиотеки, затем SQLite/WASM для
   большого опубликованного корпуса.
4. Фоновый импорт через Web Worker.
5. Position Explorer: фильтры по игрокам, датам, турнирам и дебютам.
6. Аналитические плагины: комбинации, аномалии, дебюты, игроки, value network.
